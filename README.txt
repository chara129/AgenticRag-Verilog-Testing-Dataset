SIGR-RTL test dataset - 153 problems (spec-to-RTL)

Each problem has three files:
  ProbNNN_name_prompt.txt  - natural-language specification given to the pipeline
  ProbNNN_name_ref.sv      - reference RTL (used only by the grader)
  ProbNNN_name_test.sv     - grading testbench (used only by the grader, never by the pipeline)

problems.txt lists all 153 problem names.
